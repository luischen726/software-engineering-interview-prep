## Fleeting note
- Exponentiation `**` `alert( 2 ** 2 ); // 2² = 4`
- what is logical operators? 
  - There are four logical operators in JavaScript: || (OR), && (AND), ! (NOT), ?? (Nullish Coalescing). they are called “logical”, they can be applied to values of any type, not only boolean.
- The nullish coalescing operator is written as two question marks `??`. a value is “defined” when it’s neither `null` nor `undefined`

- Javascript Array is object instead of primitive 
- Javascript Array are resizable and can contain a mix of different data types
- JavaScript arrays are not associative arrays that string can not be use as index
- JavaScript array's index starts from 0 (zero-indexed)
- Any Javascript provide array-copy operations are Shallow copy
## Literature note
- Javascript Array is not primitive. it is an ordered collection of elements which can contain different type of data. Javascript Array is resizable and contain a mix of different data types. JavaScript allows us to create arrays using `[]`, either with or without initial elements.   A common mistake that Array's index start with 0 because Javascript Array is zero-index.
