## Readiness levels

```
🔴 Not ready to apply
"I cannot build or explain basic backend software yet."

🟡 Ready to apply + continue studying
"I can do the core job, but interviews expose knowledge gaps."

🟢 Strong interview readiness
"I can explain, code, debug, test, and discuss trade-offs confidently."
```

## What is cord job?
- The work the company is actually paying you to do repeatedly.
    ```less 
    Company needs a feature
            ↓
    You understand the requirement
            ↓
    Write/change backend code
            ↓
    Read/write database data
            ↓
    Test it
            ↓
    Fix problems
            ↓
    Ship it
            ↓
    Maintain it when something breaks
    ```
## How do i notice the core job

- core job example: 
    ```
    - What you'll do
        - Build REST APIs
        - Maintain services
        - Design database schemas
        - Write tests
        - Debug production issues
        - Integrate external APIs
        - Review code
        - Collaborate with frontend/product
    ```
- tool example for core job
    ```less
    Requirements

    Node.js
    TypeScript
    PostgreSQL
    Redis
    Docker
    AWS
    Kafka
    Kubernetes
    ```
- idea
    ```
    "Build an API"
       ↑
    CORE JOB

    "Node.js"
        ↑
    TOOL used to do the core job
    ```
